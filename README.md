# System Reporter 🦀

Легковесное приложение-сборщик системной информации на Rust, которое собирает данные о системе и сохраняет их в JSON-файл.

## ✨ Особенности

- **Кроссплатформенность**: Работает на Windows, Linux и macOS
- **Минимальные зависимости**: Использует только проверенные крейты
- **Простота использования**: Запустил - получил отчет
- **Расширяемость**: Легко добавить дополнительные модули

## 📋 Собираемая информация

### Модуль 1: Базовая информация
- Имя пользователя
- Имя хоста
- Операционная система и версия
- Время работы системы (uptime)

### Модуль 2: Оборудование
- Модель и бренд процессора
- Количество ядер CPU
- Общая и используемая память (RAM)
- Список дисков с размерами и типами

### Модуль 3: Сетевая информация
- Локальный IP-адрес
- MAC-адреса всех сетевых адаптеров

### Модуль 4: Программное обеспечение
- Количество запущенных процессов
- Полный список процессов
- Обнаружение подозрительных процессов (VM/Sandbox детектор)

## 🚀 Установка и запуск

### Предварительные требования

**Rust** (версия 1.70+)

```bash
# Установка Rust через rustup
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Для Windows: Скачайте установщик с https://rustup.rs/
```

### Быстрый старт

```bash
# 1. Клонирование репозитория
git clone <repository-url>
cd ytt

# 2. Сборка проекта
cargo build --release

# 3. Запуск
cargo run --release
```

Или сразу запустить без сборки:

```bash
cargo run
```

### Результат работы

После выполнения в текущей директории будет создан файл `report.json` с полной информацией о системе в структурированном JSON-формате.

## 📝 Как это работает

1. **Инициализация**: Создаются экземпляры системных библиотек
2. **Сбор данных**: Приложение собирает информацию через:
   - `sysinfo` - кроссплатформенная информация о системе
   - `whoami` - информация о пользователе
   - `std::net` - сетевая информация
3. **Сериализация**: Все данные упаковываются в структуру `SystemReport` и сериализуются в JSON
4. **Сохранение**: JSON-файл записывается в текущую директорию

## 🛠️ Разработка

### Структура проекта

```
ytt/
├── Cargo.toml          # Манифест проекта и зависимости
├── src/
│   └── main.rs         # Основной код приложения
├── README.md           # Документация
├── .gitignore          # Игнорируемые файлы
└── target/             # Скомпилированные файлы (создается при сборке)
```

### Основные зависимости

- `sysinfo` (v0.30) - кроссплатформенная системная информация
- `whoami` (v1.5) - информация о пользователе
- `serde` + `serde_json` (v1.0) - сериализация в JSON

### Расширенные возможности

В `Cargo.toml` закомментированы дополнительные зависимости для расширенной функциональности:

```toml
# Раскомментируйте для добавления:

# Windows Management Instrumentation
# wmi = "0.15"

# Отправка в Telegram
# tokio = { version = "1", features = ["full"] }
# teloxide = { version = "0.12", features = ["macros", "fs"] }
# local-ip-address = "0.6"
```

## 🔧 Расширение функционала

### Добавление новых модулей сбора данных

```rust
// В функции collect_system_info() добавьте:
custom_data: collect_custom_data(),

// Реализуйте свою функцию:
fn collect_custom_data() -> Vec<String> {
    // Ваша логика
    vec!["data1".to_string(), "data2".to_string()]
}
```

### Добавление отправки в Telegram

1. Раскомментируйте зависимости в `Cargo.toml`
2. Установите переменные окружения:
   ```bash
   export TELEGRAM_BOT_TOKEN="your_token"
   export TELEGRAM_CHAT_ID="your_chat_id"
   ```
3. Добавьте код отправки после сохранения отчета

## 🐛 Устранение неполадок

### Ошибка компиляции
Обновите Rust до последней версии:
```bash
rustup update
```

### Проблемы с доступом к crates.io
Если cargo не может загрузить зависимости, проверьте:
- Интернет-соединение
- Настройки прокси (если используется)
- Обновите индекс: `cargo update`

### Проблемы с правами доступа
На Linux/macOS может потребоваться запуск с sudo для доступа к некоторой системной информации:
```bash
sudo cargo run --release
```
